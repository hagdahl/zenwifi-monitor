# Security reporting

Do not report vulnerabilities, secrets, or environment-specific information in public issues. Report privately through [GitHub Private Vulnerability Reporting](https://github.com/hagdahl/zenwifi-monitor/security/advisories/new) and include only the minimum necessary technical evidence.

This project never stores router passwords or Notion tokens in the repository. If a secret is exposed, rotate it before further use.
